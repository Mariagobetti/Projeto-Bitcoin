# 📊 Projeto-Bitcoin

Dashboard interativo do preço do Bitcoin usando API real e Chart.js

## 🚀 Sobre o Projeto
Aplicação web que consome a API da CoinGecko para exibir o preço do Bitcoin em tempo real com gráfico interativo.
Feito para praticar consumo de API, JavaScript e visualização de dados.

## 🛠️ Tecnologias
- `HTML5`
- `CSS3` 
- `JavaScript`
- `Chart.js`
- `API CoinGecko`

## ✨ Funcionalidades
- [x] Gráfico de linha do preço do BTC nas últimas 24h
- [x] Atualização automática dos dados
- [x] Layout responsivo
